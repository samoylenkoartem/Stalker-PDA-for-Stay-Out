# Stalker PDA for Stay Out

🗺️ AI-компаньон для онлайн-игры Stay Out — автоматически отслеживает игровые события в реальном времени и генерирует тактические отчёты.

## Что умеет

- 📊 Отслеживает HP через анализ пикселей экрана
- 🔍 Автоматически находит полоску HP на любом разрешении (`find_hp_bar`)
- 💾 Логирует ранения, лечение и события чата в SQLite с полями `location` и `damage_source`
- 🔴 Black Box режим — повышает частоту опроса при критическом HP (<30%)
- 💬 Читает игровой чат через OCR (pytesseract) с нечётким поиском (fuzzywuzzy)
- ⚙️ Настройка ключевых слов через UI при запуске (tkinter)
- 🧵 Параллельная обработка: три потока (HP / Чат / БД) через threading + Queue
- 🤖 Генерирует AI-отчёт по итогам сессии через Groq/Llama
- 🪟 Динамически привязывается к окну игры

## Стек

Python · SQLite3 · pytesseract · pygetwindow · pyautogui · fuzzywuzzy · tkinter · threading · Groq API (Llama 3.1)
